# HarGharShop — Complete Full-Stack E-commerce Demo

## ⭐ One-click run (Windows)

1. Extract this ZIP.
2. Double-click **START_HARGHARSHOP.bat**.
3. It automatically installs frontend/backend dependencies and opens the website.
4. Keep the two terminal windows open while using the site.

Website: http://localhost:5173
Backend health: http://127.0.0.1:5000/api/health

## One-server mode

Double-click **START_ONE_SERVER.bat**. It builds the React frontend and then starts Flask. This mode is useful when you want frontend + backend served together by one server.

## Features
- 50+ seeded products across mobiles, electronics, fashion, footwear, home, beauty and groceries
- Search, category/subcategory filters and sorting
- Product details, wishlist and cart
- Login/register and session support
- Checkout and order history
- Admin product creation/deletion and order status updates
- SQLite database auto-created on first backend start
- Vite API proxy so frontend and backend work together without changing API URLs

## Requirements
- Windows 10/11
- Python 3.10+
- Node.js LTS (npm)

If PowerShell blocks a script, do not run a `.ps1` file: just double-click the `.bat` file.
